# Taco Bella's - Astro Site

Taco Bella's website built with Astro, React, and Tailwind CSS.

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Vercel Deployment

**Important:** In Vercel project settings, make sure:
- **Root Directory**: Leave blank (or set to `.`) - NOT `frontend`
- **Framework Preset**: Other
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
